# Hyprr Brands — logo kit

**Rebuilt 6 Sep 2026 as true vector.** The file previously in use was a 200×52px PNG, which is
usable only in a small web header at 1× and soft everywhere else. These replace it everywhere.

The wordmark is set in **Space Grotesk Bold**, the brand typeface, so the logo and the site now
share a type system. The dot is **Violet `#6947FF`**, taken from the original file.

---

## What to use where

| Where | File |
|---|---|
| Website header, light background | `hyprr-logo-primary.svg` |
| Website header, dark background | `hyprr-logo-reversed.svg` |
| Anything on the petrol brand colour | `hyprr-logo-on-petrol.svg` |
| Email signature, PDF, Word, PowerPoint | `hyprr-logo-primary-1024.png` |
| Invoices, contracts, one-colour print | `hyprr-logo-mono-black.svg` |
| Over photography or video | `hyprr-logo-mono-white.svg` |
| Social profile picture (LinkedIn, X, Instagram) | `hyprr-icon-petrol-512.png` |
| WhatsApp Business, Google Business Profile | `hyprr-icon-petrol-512.png` |
| Apple touch icon | `hyprr-icon-petrol-180.png` |
| Browser tab | `favicon.ico`, plus `favicon-32.png` |

**Always prefer the SVG on the web.** It is a few kilobytes, sharp at any size and any zoom, and
it recolours in CSS. The PNGs exist for tools that cannot take SVG — Office, email clients, some
social platforms.

---

## Rules

**Clear space.** Keep empty space around the logo equal to half the height of the letters. It is
built into the SVG viewBox, so do not crop the files.

**Minimum size.** 120px wide on screen, 25mm in print. Below that use the square icon instead of
the wordmark.

**Do not:** stretch it, rotate it, add a shadow or outline, recolour the letters to anything other
than the variants supplied, place the primary version on a dark background, or place the reversed
version on a light one.

**The violet dot stays violet** on light and dark backgrounds. The one exception is the petrol
variant, where it becomes citrus so it stays visible against the teal.

## One thing to check

These are rebuilt to match the original wordmark closely, but they are a reconstruction, not the
designer's source file. If whoever made the original still has the vector, compare the letterforms
side by side before rolling these out — the spacing between "hyprr." and "brands" is the detail
most likely to differ. If no source file exists, these become the master.
